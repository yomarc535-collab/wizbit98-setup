Welcome to the Wizbit Assistant 98 Setup Wizard

This wizard will install Wizbit, a little blue helper who lives in your browser and helps with homework, forms, error messages and anything else on the page.

No API key is needed, and it only takes a moment. Click Next to continue, or Cancel to exit Setup.

What's new in 2.0
  • Highlight text and click Explain, Summarize or Ask
  • Properties window: looks, sounds, personality, privacy
  • Study tools: quiz me, flashcards, focus timer, step-by-step guide, compare texts
  • Sticky notes that stay on a page, plus a Recycle Bin to throw them away
  • Right-click menu and a Win98 shutdown screen
  • Error dialogs, a file-copy startup, a new professor
  • Privacy preview, per-site off switch, hidden passwords

Information

Please read the following notice before continuing.

PRIVACY NOTICE

No API key needed. When you ask a question, the page text Wizbit can see plus your question are sent to the free Pollinations AI service (text.pollinations.ai), so only use it on pages you're okay sharing.

Passwords, card numbers and similar fields are never sent, and Wizbit stays out of banking and webmail sites unless you say otherwise.

Open his Properties window (the * button) to see exactly what's sent before it goes, turn off page sharing, or add sites he should avoid.

He can also open new tabs and web searches, but only after you click Yes.

Optional components

Follow-me mode (needs the free Tampermonkey extension)

A bookmark only lives in the tab where you click it, so with the bookmark Wizbit stays behind when he opens a new tab. The Tampermonkey version carries him over: he hops into the new tab and keeps the conversation going, and he can keep working on a multi-page task even when a click loads a brand-new page. Press Alt+Shift+W on any page to call him.

Then: Tampermonkey icon → Create a new script → delete the template, paste, press Ctrl+S.

Meet the whole cast

He can turn into animals, shapes and planes, and a smoky professor shows up for the hard questions. Right-click him for a menu, and try the Konami code.

Completing the Wizbit Assistant 98 Setup Wizard

Setup has finished installing Wizbit. Open any page, click the bookmark, and ask him anything.

Some sites (GitHub, many banks, some schools) block bookmarks, so use the follow-me version on those. If it ever misbehaves, the README has a few fixes.

Click Finish to close Setup.
